# Luis's Island

My portfolio as a pixel-art island in the style of the Game Boy and Pokémon games I grew up with.
Walk Luis (me, as a charro) around the island; walk up to a place to visit one of my projects.

Live: https://panter15.github.io/

| Place | Opens |
|---|---|
| Library with a cat sign | GitHub |
| Consulate with the US flag | Easytravel Visa |
| Blue and white lighthouse | LinkedIn |
| Chiva boat in Colombian colours | Danza Folclor |

## How it works

- **Angular 20** (standalone components, signals). One `requestAnimationFrame` loop, run outside Angular, moves Luis,
  the camera and the animals; signals update only what changed.
- **Art** is generated by plain Node scripts with no dependencies:
  - `art/town.js` builds the top-down island from the [Ninja Adventure](https://pixel-boy.itch.io/ninja-adventure-asset-pack)
    tilesets (CC0, credited in `art/tilesets/ninja-adventure/CREDITS.md`), recoloured to the island's own palette.
    It adds La Malinche (`art/malinche.js`), the hand-drawn consulate, lighthouse and chiva boat, and writes
    `public/town/` plus `src/app/island/town-data.ts` (collision grid, places, animated decor).
  - `art/avatar.js` draws Luis (every view and animation frame) and his horse.
  - `art/luis-piskel.js` round-trips Luis through [Piskel](https://www.piskelapp.com) for hand editing.
- **Walking** uses a breadth-first search over the tile grid (`src/app/island/walk.ts`) for tap-to-walk and for the
  animals that roam the island. Luis and the animals collide.
- **Controls**: arrow keys / WASD, tap to walk, or the on-screen Game Boy D-pad and A/B buttons. On upright phones the
  page becomes a Game Boy.
- **Accessible**: every place is a real button (Tab + Enter), animations stop with "reduce motion", and *Classic view*
  lists the same links as plain text.

## Run it

```bash
npm install
npm start               # http://localhost:4200
npm test                # walking, routes, reachability, collisions

node art/avatar.js      # after changing Luis or the horse
node art/town.js        # regenerate the island (run after avatar.js)
```

Deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.
