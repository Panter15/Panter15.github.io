# Luis's Island

My portfolio as a pixel-art island in the style of the Super Nintendo / Game Boy Advance games I grew up with.
Turn the island with the side arrows, a drag or the mouse wheel, and click a building to visit a project.

Live: https://panter15.github.io/

## How it works

- **Angular 20** (standalone components, signals). The island is a CSS 3D scene with no game engine: the ground image
  lies on a tilted plane (the SNES "Mode 7" look), and every building and tree is a sprite that turns to face the
  camera. The houses and the boat have four drawings (front, sides, back) that swap as the island turns.
- **GSAP** animates the camera: turning, and zooming in on a building.
- **Art** is generated by `art/render3.js` (plain Node, no dependencies), which writes the ground, the sprites and
  `src/app/island/island-data.ts`. Hand edits can be made in [Piskel](https://www.piskelapp.com) with
  `art/luis_island.piskel`.
- **Accessible**: every building is a real button (Tab + Enter), arrow keys turn the island, and *Classic view* lists
  the same links as plain text.

## Run it

```bash
npm install
npm start                # http://localhost:4200
cd art && node render3.js   # regenerate the art (run inside art/)
```

Step-by-step build guide (Spanish), with the reasons behind every decision: [docs/GUIA.md](docs/GUIA.md).

Deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.
